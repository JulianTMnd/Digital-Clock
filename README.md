# Digital-Clock
ESP32 digital clock featuring custom PCB design  built with ESP-IDF.

An embedded systems project built around the ESP32 microcontroller. This repository contains the full hardware, and firmware source files for a precision digital clock and temperature monitor. This project showcases real-time task management using FreeRTOS, I2C peripheral integration (AHT10 and DS3231) and custom PCB layout. 

The custom PCB for this project was designed from the ground up using KiCad. The following ray-traced render showcases the board layout, emphasizing efficient component placement and signal routing for the ESP32 microcontroller and its external modules.
